# U2-03c: Guild of the Grumpy Old Hackers


The hackers found a LinkedIn account and its password from the 2012 LinkedIn breach. The password was "yourefired". They tried it on Donald Trumps Twitter account. It worked because he had used the password.

Credential reuse means using the password on different accounts. If one account gets hacked the same password can then be used to get into accounts too. This is what happened with LinkedIn and Twitter.

The main CIA principle here was confidentiality. The hackers got access, to an account that they were not supposed to access private information was no longer fully protected.

Credential stuffing is when hackers take leaked usernames and passwords and try them on other websites. It is quite common because people often use the passwords on multiple accounts.

Even though the target was an important and famous person the attack was actually very simple. The hackers did not need a technical exploit because the reused password gave them access.

Using a password for every important account would have helped a lot. Turning on MFA would also make it much harder to log in even if someone got the password.

The LinkedIn breach happened in 2012. The password was still useful four years later. This shows that leaked passwords can stay dangerous for a time.

After watching this episode I would check my email with Have I Been Pwned. I would also make sure my important accounts have passwords and MFA turned on.
